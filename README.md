# CV Project - Vatsiniana Rinah

## Description

This project is a **single-page CV** created using **pure HTML**.  
The main goal is to **practice structuring content semantically**, including sections for **education, skills, and professional experience**.  
Styling (CSS) and design will be addressed in future projects.

---

## Features

- Semantic HTML structure with `<header>`, `<section>`, `<footer>` tags.
- Sections included:
  - **Header**: Name, title, contact information.
  - **Education**: Academic background.
  - **Skills**: Technical skills.
  - **Experience**: Career history.
- **SEO meta tags** included for better search engine indexing.
- **Open Graph tags** prepared for social media sharing.
- **Favicon** included (SVG or PNG).
